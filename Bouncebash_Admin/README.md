# BounceBash Staff Interface

This folder contains the staff sign-in, dashboard, bookings, calendar, reports, packages, blog and feedback, and settings pages. The layout uses HTML and CSS, with JavaScript for navigation and operational features.

Start the Node.js server from the project root, then open `http://localhost:3000/Bouncebash_Admin/login.html`. Staff authentication and operational tools use the API and database. See the [project README](../README.md) for setup and staff account creation.
